# Login Page with API

## Description
This is a simple login page project that uses API integration for user authentication.

## Features
- User Login
- API Call
- Error Handling
- Simple UI

## Tech Stack
- Python
- Flask
- HTML/CSS
- JavaScript

## How to Run
1. Download the project
2. Open it in VS Code
3. Run app.py

## API Working
- An API call is triggered when the login button is clicked
- Login is successful if the entered data is correct
- An error message is shown for incorrect credential
